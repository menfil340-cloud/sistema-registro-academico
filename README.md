
# Sistema de Registro Académico

## Descripción
Programa desarrollado en Python para registrar y evaluar
las calificaciones de tres estudiantes.

## Funcionalidades
- Registro de nombres y apellidos.
- Ingreso de notas de dos parciales.
- Manejo de errores mediante try-except.
- Cálculo del promedio final.
- Clasificación del estado académico.

## Reglas de evaluación
- Promedio menor que 60: Reprobado.
- Promedio mayor que 95: Sobresaliente.
- Los demás promedios: Aprobado.

## Requisitos
Tener Python instalado.

## Ejecución
Ejecutar el siguiente comando en la terminal:

python main.py
